# project-ecom

E-commerce backend REST API built with Node.js, Express, TypeScript, and MongoDB.

## Setup

```bash
npm install
npm run dev
```

Server runs at `http://localhost:8080`

## Scripts

| Command | Description |
|---|---|
| `npm run dev` | Start dev server |
| `npm run build` | Compile TypeScript |
| `npm start` | Run compiled output |
